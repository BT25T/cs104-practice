# CS104 practice repository

Welcome! This repository is where you practise the GitHub workflow you will use for every
homework in CS104BKK.

## Instructions

1. **Fork** this repository (button at the top right of this page).
2. **Clone** your fork to your laptop. In VS Code: *Clone Git Repository* → pick
   `github.com/<your-username>/cs104-practice`.
3. Create `students/about_<your-github-username>.py`. It must:
   - print your name and where you are from,
   - ask for your birth year,
   - print the age you turn this year and your birth year in the Buddhist Era (BE = year + 543).
4. Run it from the terminal: `python3 students/about_<your-github-username>.py`
   (Windows: `py students\about_<your-github-username>.py`).
5. **Commit** with a clear message, e.g. `Add about_nok.py`, and **push**.
6. On GitHub, open a **pull request** from your fork to this repository.
7. Paste the link to your pull request in Google Classroom.

See `students/about_example.py` for the expected output format.
